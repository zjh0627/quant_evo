# Quant Evo - 量化交易系统

基于机器学习的A股量化交易系统,支持多因子选股、策略回测和模拟交易。

## 功能特性

- **多因子模型**: XGBoost + LSTM 混合预测
- **信号因子**:
  - 趋势追踪因子
  - 均值回归因子
  - 动量因子
  - 新因子(成交量异动、布林带收窄、动量加速)
  - CFFEX机构持仓因子 (中信期货净空单反向指标)
  - 融资融券情绪因子
- **策略优化**: ICIR动态权重调整
- **回测引擎**: 支持止损止盈、仓位管理
- **实时信号**: 每日自动生成交易信号

## 因子说明

### CFFEX机构持仓因子
中信期货在股指期货上的净空单变化可作为市场反向指标:
- 净空单大幅增加 → 市场可能反弹 (BULLISH)
- 净空单大幅减少 → 市场可能回调 (BEARISH)

### 融资融券情绪因子
融资融券余额变化反映市场杠杆情绪:
- 融资余额大幅增加 → 市场过热预警 (BEARISH)
- 融资余额大幅减少 → 恐慌见底信号 (BULLISH)

## 回测结果

| 场景 | 年化收益 | 夏普比率 | 最大回撤 |
|------|---------|---------|---------|
| 基准 | -76.90% | -4.78 | -29.05% |
